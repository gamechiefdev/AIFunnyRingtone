Five designer skills applied

  1. Masonry rhythmPins of mixed heights create the Pinterest waterfall instead of a rigid grid.
  2. Soft elevation24–26dp radii, 1dp hairline strokes and near-zero shadows replace hard borders.
  3. Typographic scaleOne family (Poppins) across 6 sizes, tighter tracking on display text.
  4. Warm neutral canvas#FBF9F6 surfaces let the green brand and coral accents breathe.
  5. Micro-interactionRipple cards, a sliding nav indicator and a save affordance on every pin.

What actually changed in the code

UI layer only — layouts, styles, colours, dimens, drawables, fonts, plus a handful of layout-manager / label lines in Java. No API, Firebase, ads, billing or data logic touched.

Shell & navigation

activity_main.xml · MainActivity.java · headerfile.xml

  • 42dp flat top bar with centred title → floating app bar, two-line title, round action buttons
  • solid green tab bar, white icons only → rounded white bar + sliding 4dp indicator
  • resetIconColors(): white → nav_unselected so idle tabs read on white

Home discovery

fragment_home.xml · Home.java

  • “AI Generator” label + 2 flat ratio images → hero headline + gradient AI Studio pins
  • two fixed 4-icon rows → masonry columns of eight coloured pins
  • 3-column rigid category grid → 2-column pin grid
  • new: mood chips that filter the existing categoryList (same intent extras)

Wallpapers

activity_wallpaper_list.xml · bg_layout.xml · wall_itemlayout.xml · Wall_Adapter.java

  • 200dp uniform cards, 10dp radius, green 1dp stroke → 26dp pins, scrim + badge, 2dp shadow

  • header gains a subtitle; grid padding tightened

Stickers
